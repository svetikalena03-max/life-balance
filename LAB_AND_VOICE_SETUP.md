# Разбор анализов и озвучка практик

Раздел `/labs` доступен после входа с главной страницы и из «Здоровье».
Пользователь разрешает обработку сервисами Яндекса, добавляет текст/одностраничный
PDF/JPEG/PNG до 2 МБ, затем сверяет редактируемые карточки с бланком.
Объяснение отправляется только после подтверждения проверки. Файлы, текст и ответ
не пишутся в Supabase, localStorage и историю приложения. Обработка у провайдера
подчиняется его условиям; заголовок логирования OCR и YandexGPT выключен.
Не загружать реальные данные при технической проверке — использовать вымышленные.

Численный статус рассчитывается кодом по введённым единицам и референсному интервалу.
Для пропущенных/неоднозначных норм, качественных результатов и значений с `<`/`>`
показывается необходимость проверки. LLM даёт только пояснение и вопросы врачу.
Не использовать результат для медицинских решений без врача. Референсный интервал
не определяет порог медицинской срочности; приложение не выполняет триаж.

## Сервисы Яндекса

Используются существующие серверные `YANDEX_CLOUD_API_KEY`,
`YANDEX_CLOUD_FOLDER_ID` и `YANDEX_AI_MODEL`.
Если текущий ключ имеет права только YandexGPT, OCR и голос потребуют отдельных прав.
Можно задать отдельные ключи `YANDEX_VISION_API_KEY`, `YANDEX_SPEECHKIT_API_KEY`.
Не добавлять ключи в репозиторий и не использовать префикс VITE_.

- OCR: https://aistudio.yandex.ru/en/docs/vision/operations/ocr/text-detection-image
- Синтез: https://aistudio.yandex.ru/en/docs/speechkit/tts/request
- Голос: `marina`, `friendly`, русский, скорость 0.9, MP3.
- Endpoint OCR: https://ai.api.cloud.yandex.net/ocr/v1/recognizeText
- Endpoint TTS: https://tts.api.cloud.yandex.net/speech/v1/tts:synthesize

Новые сервисы могут тарифицироваться отдельно по условиям Yandex Cloud.
Озвучиваются только фиксированные тексты трёх практик: медитация, тяга, расслабление.
Результаты и параллельные запросы кэшируются в памяти серверного процесса; после
холодного запуска возможен повторный синтез. На клиенте аудио остаётся в памяти
только пока открыта практика. Перед началом нажать «Подготовить голос Яндекса»,
затем «Послушать голос» или «Начать». При недоступности облачного голоса можно
выбрать голос устройства или отключить озвучку.

## Проверка перед закрытием задачи

- `node --test scripts/lab-analysis.test.ts` проверяет сравнения, неоднозначные нормы,
  полноту ответа, сигнатуры файлов, флаг логирования OCR и кэш синтеза на моках.
- `npm run build`, `npx tsc --noEmit`, eslint изменённых файлов.
- В рабочем приложении проверить OCR на вымышленном бланке и синтез одной практики.
  Моки не подтверждают права производственного ключа и качество звучания.
- На iPhone проверить паузу, продолжение, смену практики и фон между фразами.
