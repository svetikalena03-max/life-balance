# Письмо подтверждения регистрации

Готовый текст: `confirmation.html`.
Тема: **Подтвердите регистрацию в «Балансе жизни»**.

## Применение к рабочему проекту

Файл в репозитории сам по себе не меняет письма рабочего Supabase.

1. Открыть Supabase → Authentication → Emails → Confirm sign up.
2. Вставить тему и HTML из `confirmation.html`.
3. Сохранить и отправить тестовое письмо на собственную почту.
4. Проверить русский текст и переход по кнопке в приложение.

Переменная `{{ .ConfirmationURL }}` сохраняет существующий механизм подтверждения. Не заменять её статической ссылкой на приложение.

Документация: https://supabase.com/docs/guides/auth/auth-email-templates
